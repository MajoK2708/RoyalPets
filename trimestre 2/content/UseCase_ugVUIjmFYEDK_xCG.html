Cliente/Veterinario
Steps
1. El administrador y veternario ingresan al aplicativo web.
2. El administrador y veternario ingresan al módulo “Mascotas”.
3. Seleccionan “Registrar mascota”.
4. El sistema muestra formulario.
5. Ingresan nombre de la mascota.
6. Seleccionan especie.
7. Ingresan raza.
8. Ingresan edad.
9. Ingresan peso.
10. Registran señas particulares.
11. El veterinario socia la mascota al dueño.
12. Presiona “Guardar”.
13. El sistema valida datos.
14. Guarda la información en la base de datos.
15. if (los datos son válidos)
    15.1. El sistema guarda la información en la base de datos.
    15.2. El sistema muestra mensaje de confirmación.
16. else
    16.1. El sistema muestra mensaje de error en los datos ingresados.
    16.2. El usuario debe corregir la información del formulario.
    end if
