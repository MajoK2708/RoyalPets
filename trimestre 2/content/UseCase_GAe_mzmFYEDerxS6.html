Use Case Note
■ Workflow
    • // Write down briefly how user perform the work
    • El veterinario accede al sistema e inicia sesión.
    • Busca la consulta de la mascota registrada previamente.
    • Selecciona la opción Registrar tratamiento.
    • Ingresa los datos del tratamiento (medicamentos, dosis, duración, recomendaciones).
    • El sistema valida la información ingresada.
    • El sistema guarda el tratamiento y lo asocia al historial clínico de la mascota.
    • El sistema confirma que el tratamiento fue registrado correctamente.
■ Business Logic
    • // Write down what user expect the system to react upon certain condition (e.g. low inventory alert level)
    • Solo los usuarios con rol de veterinario pueden registrar tratamientos.
    • El tratamiento debe estar asociado a una consulta existente.
    • Los campos medicamento, dosis y duración son obligatorios.
    • El tratamiento registrado se guarda automáticamente en el historial clínico de la mascota.
    • El sistema debe registrar la fecha y el veterinario responsable del tratamiento.
■ Decisions
    • // Write down the decisions made during the meeting (e.g. Must allow accessing from mobile devices)
    • Permitir registrar más de un medicamento en un mismo tratamiento.
    • Guardar automáticamente el tratamiento en el historial clínico.
    • Permitir que el veterinario edite el tratamiento si hubo un error.
■ Follow-up
    • // Write down the items that should follow-up in the coming meeting
    • Definir si el sistema permitirá generar una receta automática basada en el tratamiento.
    • Evaluar si se debe enviar recordatorio al cliente sobre la administración del medicamento.
    • Revisar si el tratamiento puede actualizarse después de la consulta.

Scenario
Steps
1. El veterinario inicia sesión en el sistema.
2. El veterinario selecciona la consulta de la mascota.
3. El veterinario selecciona la opción Registrar tratamiento.
4. El sistema muestra el formulario para registrar el tratamiento.
5. El veterinario ingresa los datos del tratamiento (medicamento, dosis, duración y recomendaciones).
6. if los datos ingresados están completos y la consulta existe
    6.1. El sistema valida la información ingresada.
    6.2. El sistema guarda el tratamiento en el historial clínico de la mascota.
    6.3. El sistema muestra un mensaje de confirmación indicando que el tratamiento fue registrado exitosamente.
7. else
    7.1. El sistema muestra un mensaje de error indicando que faltan datos o que la consulta no es válida.
    7.2. El veterinario debe corregir la información antes de continuar.
   end if
