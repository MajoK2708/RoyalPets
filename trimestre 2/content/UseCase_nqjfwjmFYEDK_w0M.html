Admin/Cliente/Veterinario
Steps
1. Los usuarios ingresan al aplicativo webaccede al módulo “Usuarios”.
2. Seleccionan la opción “Registrar usuario”.
3. El sistema muestra formulario de registro.
4. Los usuarios ingresan: nombre, documento, correo, teléfono y contraseña.
5. El sistema selecciona el rol del usuario automaticamente.
6. Presionan “Guardar”.
7. El sistema valida campos obligatorios.
8. if
    8.1. El sistema valida el formato del correo.
    8.2. El sistema verifica que el correo no exista previamente.
    8.3. El sistema encripta la contraseña.
    8.4. El sistema guarda el usuario en la base de datos.
    8.5. El sistema muestra el mensaje: "Usuario registrado exitosamente".
9. else
    9.1. El sistema muestra el mensaje: "El correo ya se encuentra registrado".
    9.2. El sistema muestra el mensaje: "Formato de correo inválido".
    9.3. El sistema muestra el mensaje: "Debe completar todos los campos obligatorios".
   end if
