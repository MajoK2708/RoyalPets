Description

Cuando un usuario ingresa datos (por ejemplo, al registrar un servicio, un usuario o un rol), el sistema valida los campos obligatorios, formatos y consistencia, mostrando errores si es necesario.

Use Case Note
■ Workflow
    • // Write down briefly how user perform the work
    • El usuario ingresa datos en un formulario.
    • El sistema realiza validaciones automáticas.
    • El sistema informa si los datos son correctos o muestra errores.
■ Business Logic
    • // Write down what user expect the system to react upon certain condition (e.g. low inventory alert level)
    • Los campos obligatorios no pueden quedar vacíos.
    • Se valida formato de correo, número de documento y fechas.
    • Se verifica consistencia con datos existentes (por ejemplo, que la mascota exista antes de registrar un servicio).
■ Decisions
    • // Write down the decisions made during the meeting (e.g. Must allow accessing from mobile devices)
    • Validación puede ocurrir en tiempo real o al enviar formulario.
    • Los errores se muestran inmediatamente al usuario.
    • Si hay inconsistencias, no se guarda la información hasta que se corrija.
■ Follow-up
    • // Write down the items that should follow-up in the coming meeting
    • Permitir reintentos de ingreso de datos.
    • Registrar intentos fallidos de ingreso para auditoría.
    • Reutilizar este caso de uso en otros procesos que requieran validación.

Scenario
Steps
1. El usuario ingresa datos en un formulario del sistema.
2. El sistema recibe la información y comienza la validación.
3. if Todos los campos obligatorios están completos.
    3.1. Los formatos son correctos (correo, fecha, números, etc.).
    3.2. La información es consistente con datos existentes en la base de datos.
    3.3. El sistema marca los datos como válidos.
    3.4. El usuario puede continuar con el siguiente paso (guardar, enviar o registrar).
4. else
    4.1. El sistema muestra mensajes de error indicando los campos inválidos o inconsistentes.
    4.2. El usuario corrige la información.
    4.3. El sistema vuelve a validar los datos.
   end if
