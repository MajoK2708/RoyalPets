 UseCase : Use Case
 Registrar servicio adicional : Use Case

El cliente ingresa al módulo de servicios adicionales, registra un nuevo servicio para su mascota y el sistema valida y almacena la información correctamente.

 Actualizar servicio adicional : Use Case

El cliente accede a un servicio adicional registrado, realiza cambios en su información y el sistema valida y guarda las actualizaciones.

 Leer servicio adicional : Use Case

El cliente accede al módulo de servicios adicionales, selecciona un servicio y el sistema muestra su información detallada.

 Cancalar servicios adicional : Use Case

El cliente selecciona un servicio adicional y solicita su cancelación; el sistema valida la operación y actualiza el estado del servicio.
