  Registrar usuario : Use Case

Permite crear un nuevo usuario en el sistema ingrensando su información básica                                                              

  Asignación de rol : Use Case

Define el rol del usuario (Veterinario,Adimistrador o cliente ), al momento del registro

  Registrar mascota : Use Case

Permite registrar una mascota asosciandola a su propietario, incluyendo datos como raza, edad, peso.

  Leer usuario : Use Case

Permite visualizar la información registrada de un usuario

  Actualizar información Usuario : Use Case

 

Permite modificar los datos personales o de contacto de un usuario

  Actualizar información Macota : Use Case

Permite modificar los datos de una mascota registrada

  Crear agendamiento : Use Case

Permite programar una cita veterinaria a una mascota

  Leer agendamiento : Use Case

Permite consultar las citas programadas

  Modificar agendamiento : Use Case

Permite cambiar la fecha, hora o detalle de una cita

  Crear consulta : Use Case

Permite registrar una nueva consulta veterinaria

  Leer historial clinico : Use Case

Permite consular el historial clinico de la mascota

  Leer consulta : Use Case

Permite visualizar la informacion de la consulta registrada

  Actualizar consulta : Use Case

 

Permirte nodificar la informacion de una consulta existente

  Crear historial clinico : Use Case

Permite registrar el historial clinico de la mascota

  Inicio sesión : Use Case

Permite que el usuario (Cliente,Veterinario y administrador), acceda al sistema ingresando sus credenciales

  Cambiar estado usuario : Use Case

Permite activar y desactivar un usuario dentro del sistema

  Validar datos : Use Case

Cuando un usuario ingresa datos (por ejemplo, al registrar un servicio, un usuario o un rol), el sistema valida los campos obligatorios, formatos y consistencia, mostrando errores si es necesario.

  Validar disponibilidad : Use Case

Verfica si el horario solicitado esta disponile antes de crear o modificar citas

  Cambiar estado mascota : Use Case

Permirte cambiar el estado de la mascota (activa, inactiva, fallecida, etc.)

  Agenda profesional : Use Case

Permite el veterinario gestionar su agenda de citas, programar consultas y organizar los horarios de atencion de las mascotas.

  Registrar tratamiento : Use Case

El vterinario ingresa y guarda en el sistema la información del tratamiento realizado a la mascota, quedando registrado en su historial clínico.

  Registrar servicio adicional : Use Case

El cliente ingresa al módulo de servicios adicionales, registra un nuevo servicio para su mascota y el sistema valida y almacena la información correctamente.

  Actualizar servicio adicional : Use Case

El cliente accede a un servicio adicional registrado, realiza cambios en su información y el sistema valida y guarda las actualizaciones.

  Leer servicio adicional : Use Case

El cliente accede al módulo de servicios adicionales, selecciona un servicio y el sistema muestra su información detallada.

  Cancalar servicios adicional : Use Case

El cliente selecciona un servicio adicional y solicita su cancelación; el sistema valida la operación y actualiza el estado del servicio.
